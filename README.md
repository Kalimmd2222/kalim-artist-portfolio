# Kalim — Artist Portfolio Starter

A responsive Next.js artist portfolio starter for live-music bookings. Design direction: warm indie-acoustic, earthy olive, cream, and cinematic placeholders.

## Run locally

1. Install Node.js 20.9 or newer.
2. Extract this folder and open it in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to a new GitHub repository.
2. Import the repository at https://vercel.com/new.
3. Keep the default Next.js settings and deploy.

## Personalise before publishing

- Replace the visual placeholders in `app/page.tsx` with real gig photographs.
- Replace the three sample video-card `url` values with your real YouTube or video URLs.
- Replace the placeholder photo blocks with your actual images from `public/images/`.
- Add your preferred booking email or WhatsApp link to the booking section.
- Personalise the artist bio and only include details and achievements that accurately describe you.

The video links and image areas are intentionally marked as placeholders; the site is a starter and should be personalised before sharing with venues.
